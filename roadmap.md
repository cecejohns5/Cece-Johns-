# Roadmap

## What this is
A study task list for language learners in Jeff Hui's AIR workshop section and anyone else learning a language. Each task is tagged with a skill, so learners can see which skill they have been avoiding.

## What Done means
A stranger can open https://cece-johns.vercel.app, create an account with an email and password, and log in. They can add study tasks tagged with one of four skills (Reading, Writing, Listening, Speaking) and mark tasks done. When they return and log in, their tasks are still there, and no other account can see them. One page shows how many tasks they have completed in each skill and names the skill or skills with the fewest, labeled "Avoiding."

## Slices
1. Sign up and log in | done-criteria: (a) In a private window on the live site, click Sign up, enter a new email and password, submit, open the confirmation email and click its link; the site shows "Signed in as" followed by that email. (b) Click Log out; the page shows a Log in link and no email. (c) Log in with the right email and a wrong password; an error message appears and you stay logged out. (d) Log in with the correct password; the page shows "Signed in as" with the email. | status: ACTIVE
2. Tasks that stay | done-criteria: (a) Logged in, type "Read one news article", choose Reading, click Add; the task appears labeled Reading. (b) Log out, close the browser, reopen the live site, log in; the task is still listed. (c) Log in as a second test account; the first account's task does not appear. (d) Tick the task's Done box and refresh; it still shows as done. | status: pending
3. Skill balance | done-criteria: (a) With 2 Reading tasks done and none in other skills, the balance section shows Reading 2, Writing 0, Listening 0, Speaking 0. (b) It shows "Avoiding:" followed by every skill tied for the lowest count. (c) Complete one Writing, one Listening, and one Speaking task and refresh; the counts update and "Avoiding:" names only the skills now lowest. | status: pending
